# ADR-0003: 결정론 고정 타임스텝 시뮬레이션

- 상태: 채택
- 날짜: 2026-08-13

## 맥락
Hive 확장 스토리의 핵심이 "리플레이 = 입력 시퀀스" 방식의 해법 공유 피드다.
이 방식은 게임이 결정론적일 때만 성립하며, 결정론은 나중에 붙일 수 없다.

## 결정
60Hz 고정 타임스텝 시뮬레이션 + 렌더 보간. Math.random() 금지(시드 PRNG만),
게임 상태 변화는 (틱 번호, 입력)만의 함수. 첫 마일스톤부터 적용한다.

## 이유
- 입력 리플레이는 스테이지당 수백 바이트라 서버 없이 Hive NoSQL DB로 UGC가 가능.
  영상 저장 방식은 스토리지·모더레이션 비용으로 불가능.
- 결정론은 순수 로직 모듈의 테스트 가능성(범위 적용 TDD)의 전제이기도 하다.
- 프레임레이트 차이로 인한 플레이 감각 편차도 제거된다.

## 고려한 대안
- 가변 dt + 나중에 결정론화: 물리 전반을 재작성하게 되어 총비용이 더 크다.
- 영상 녹화 리플레이: 위 비용 문제로 기각.

## 영향
모든 게임 로직 코드가 이 규칙의 제약을 받는다. 튜닝 값 변경은 리플레이 호환성을
깨뜨리므로, 리플레이 데이터에 버전을 함께 기록해야 한다 (구현 시 반영).
