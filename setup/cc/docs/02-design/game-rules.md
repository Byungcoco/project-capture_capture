# Game Rules

## 확정 규칙

- 퍼즐 성격: 혼합형. 클리어는 어떤 해법이든 허용, "최소 캡처 횟수"를 기록해 최적해 유도.
- 위치 규칙: 캡처 프레임 위치는 자유, 붙여넣기 위치는 반 칸(그리드 0.5유닛) 스냅.
- 지형 속성: 돌(기본) / 얼음(미끄러움, 불에 녹음) / 불(접촉 피해, 얼음을 녹임).
  같은 스탬프에 불+얼음이 담기면 붙여넣는 순간 얼음 부분이 소멸한다.
- 캡처 금지 구역: 특정 지형은 캡처 불가 태그를 가질 수 있다 (파훼 방지용).
- 레벨 지형은 박스 조합으로만 제작한다 (실루엣 볼록 껍질 방식의 전제).

## 조작 스킴 (v1 — 플레이테스트로 조정 예정)

- 이동 A/D, 점프 Space
- 카메라 회전 Q/E (홀드 시 연속 회전), 정면 정렬 F
- 마우스 이동: 캡처 프레임 조준
- 좌클릭: 캡처 → (스탬프 보유 상태) 좌클릭: 붙여넣기 / 우클릭: 스탬프 버리기
- R: 스테이지 리셋

## 레벨 커리큘럼 (기술 도입 → 발전 → 반전 → 결합)

1~3 캡처-붙여넣기 자체 (정면 고정, 속성 없음, 부분 캡처 학습 포함)
4~6 회전 도입 (특정 각도에서만 나오는 모양)
7~9 속성 도입 (얼음 → 불, "불을 프레임에서 빼는" 각도 퍼즐)
10~12 반전 (불이 도구가 되는 스테이지)
13~15 결합 (회전으로 속성을 숨기며 두 깊이를 합치는 하이라이트)
