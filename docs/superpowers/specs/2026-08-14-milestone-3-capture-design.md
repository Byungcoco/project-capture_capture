# 마일스톤 3 카메라·캡처 설계

## 목표

플레이어가 Platform에서 CaptureAim으로 전환해 직교 카메라를 360도 회전하고, 화면 비율 기반 프레임으로 박스 지형의 2D 실루엣을 캡처하여 3개 슬롯 중 하나에 저장한 뒤 SVG 디버그 미리보기로 결과를 확인한다.

## 게임 모드와 입력

- `Platform`: A/D 이동, Space 점프, 우클릭으로 CaptureAim 진입.
- `CaptureAim`: 월드 갱신 정지, 마우스로 프레임 이동, A/D로 카메라 Y축 회전, 1/2/3으로 대상 슬롯 선택, 좌클릭으로 캡처, 우클릭으로 취소.
- `Paste`: 월드 갱신 정지, 선택 슬롯과 SVG 스탬프 미리보기 표시. 우클릭으로 선택 스탬프를 버리고 Platform 복귀. 실제 배치는 마일스톤 4 범위다.
- 고정 틱 루프 호출은 유지하지만 CaptureAim/Paste에서는 `stepPlayer`와 월드 엔티티 갱신을 건너뛴다.
- CaptureAim의 조준 과정은 리플레이에 기록하지 않는다. 확정된 카메라·프레임 파라미터의 Capture 이벤트만 core 입력이 된다.

## 슬롯 규칙

- 슬롯은 3개다.
- CaptureAim 진입 시 첫 빈 슬롯을 자동 선택한다.
- 모두 차 있으면 3번 슬롯을 기본 대상으로 선택한다.
- 조준 중 1/2/3으로 대상 슬롯을 바꿀 수 있다.
- 캡처하면 선택 슬롯을 즉시 덮어쓰고 Paste로 전환한다.
- 프로토타입에는 덮어쓰기 확인창을 두지 않으며 후속 UI 후보로 남긴다.

## 카메라와 프레임

- 카메라는 현재 무대 중심을 기준으로 세계 Y축 주위를 연속 360도 회전한다.
- 초기 회전 속도는 초당 90도이며 플레이테스트로 조정할 수 있다.
- CaptureAim에서 캡처한 뒤 Paste까지는 마지막 카메라 각도를 유지한다.
- CaptureAim 취소나 Paste의 스탬프 버리기로 Platform에 복귀하면 카메라는 테스트용 초기 pose인 약 32도로 즉시 스냅한다. 향후 안정화 단계에서는 기본 pose만 정면 직교 2D 구도로 교체한다.
- 프레임은 뷰포트 너비 30%, 높이 40%의 인게임 고정 크기다.
- 프레임 중심과 경계는 화면 정규화 좌표로 표현하고 화면 경계 안으로 제한한다.
- 프레임 크기는 플레이테스트로 기본값을 조정할 수 있고, 향후 게임 규칙 정책으로 가변화할 수 있다.

## 모듈 경계와 데이터 흐름

- `core/game-mode.ts`: `Platform | CaptureAim | Paste` 전이와 선택 슬롯 번호·점유 여부만 다루는 순수 FSM. Stamp와 Three.js를 모른다.
- `capture/`: Three.js·DOM을 import하지 않는 순수 수학 모듈. 열 우선 view-projection 숫자 배열, 3D 박스, 정규화 프레임을 받아 Stamp를 만든다.
- `stamp/`: 프레임 로컬 2D 폴리곤 조각과 원본 태그를 표현한다.
- `render/`: Three.js 카메라 회전과 열 우선 view-projection 배열 제공을 담당한다.
- `ui/`: 비네트, 프레임, 슬롯 HUD, SVG 미리보기, Prototype 키 도움말을 담당한다.
- `main.ts`: 모듈을 연결하고 캡처 결과를 선택 슬롯에 저장하는 조정자다.

캡처 파이프라인은 박스의 8개 꼭짓점을 투영하고, monotone chain 볼록 껍질을 만든 뒤, Sutherland–Hodgman으로 프레임 사각형에 클리핑하고, 프레임 로컬 좌표의 Stamp로 변환한다.

## Prototype UI

- CaptureAim은 어두운 비네트와 30% × 40% 프레임으로 Platform과 즉시 구분한다.
- 슬롯 HUD는 3칸의 점유 여부와 선택 슬롯을 구분한다.
- Paste에서는 선택 슬롯의 폴리곤을 SVG 디버그 미리보기로 표시한다.
- 오른쪽 상단에 `PROTOTYPE CONTROLS` 키 도움말을 항상 표시한다.
- 도움말은 Platform, CaptureAim, Paste 조작을 모두 보여주되 현재 모드 항목을 강조하고 나머지는 흐리게 표현한다.
- CaptureAim에는 현재 카메라 각도와 선택 슬롯 번호를 디버그 텍스트로 표시한다.

## 검증

- GameMode 전이·취소, 자동 슬롯 선택, 가득 찬 슬롯의 3번 기본 선택, 수동 선택, 덮어쓰기를 Vitest로 검증한다.
- 투영, 볼록 껍질, 완전 내부·부분 교차·완전 외부 클리핑과 동일 입력의 동일 Stamp 생성을 Vitest로 검증한다.
- CaptureAim/Paste에서 플레이어 상태가 바뀌지 않는 것을 검증한다.
- `core/capture/stamp`가 Three.js·DOM을 import하지 않는지 검사한다.
- 브라우저에서 모드 가시성, 마우스 프레임 이동, A/D 360도 회전, 각도별 실루엣 변화, 슬롯 덮어쓰기, SVG 미리보기, 30% × 40% 반응형 프레임, 키 도움말과 콘솔 오류 0을 확인한다.

## 제외 범위

- Stamp의 월드 배치와 반 칸 스냅
- `THREE.Shape`·`ExtrudeGeometry` 슬래브
- 폴리곤 콜라이더와 플레이어 충돌
- 속성 상호작용, 골 판정과 캡처 횟수 제한
