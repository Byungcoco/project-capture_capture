# Capture Pipeline

입력: 현재 카메라, 화면상 프레임 사각형(고정 크기), 씬의 캡처 가능 오브젝트 목록
출력: Stamp — 프레임-로컬 좌표의 2D 폴리곤 조각 리스트, 각 조각은 원본 속성 태그 보유

1. 각 오브젝트(박스)의 8개 꼭짓점을 직교 카메라로 화면 좌표에 투영
2. 투영점들의 볼록 껍질(monotone chain)로 화면 실루엣 폴리곤 생성
3. 실루엣을 프레임 사각형으로 클리핑 (Sutherland–Hodgman)
4. 결과 폴리곤들을 프레임-로컬 좌표로 저장 → Stamp

붙여넣기: Stamp의 각 폴리곤을 THREE.Shape → ExtrudeGeometry로 얇은 슬래브 생성,
플레이어 평면(z=PLAY_PLANE)에 스냅 배치. 동일 폴리곤으로 2D 콜라이더 동시 등록.

속성 상호작용은 붙여넣기 시점에 스탬프 내부에서 해소한다 (불+얼음 → 얼음 소멸).

확장 여지(현재 범위 아님): 오목 실루엣이 필요해지면 헐 대신
렌더타겟 실루엣 + 마칭 스퀘어로 교체. 인터페이스는 Stamp로 동일하게 유지.
