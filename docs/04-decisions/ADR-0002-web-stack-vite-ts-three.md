# ADR-0002: Vite + TypeScript + Three.js 스택

- 상태: 채택
- 날짜: 2026-08-13

## 맥락
브라우저에서 바로 실행되는 웹 빌드가 제출 요건이다. 지속 가능한 코드베이스와
사람-AI 협업(직접 수정 포함)을 전제로 스택을 정해야 했다.

## 결정
Vite + TypeScript(strict) + Three.js(npm)를 사용한다. 물리는 외부 엔진 없이
자체 구현한다. React 등 UI 프레임워크는 현재 도입하지 않는다.

## 이유
- Three.js는 직교 카메라·렌더타겟 등 저수준 통제가 쉬워 캡처 파이프라인 구현에 적합.
- TypeScript strict는 AI가 생성한 코드의 오류를 컴파일 타임에 잡아 협업 안전망이 된다.
- 자체 물리: 필요한 것이 2D AABB·폴리곤 충돌뿐이라 외부 엔진(Rapier 등)은
  결정론 통제와 번들 크기에서 손해다.

## 고려한 대안
- 게임 엔진(Unity WebGL 등): 빌드 크기·로딩이 웹 제출에 불리, Codex 협업 루프도 느림.
- WebGPU 우선 렌더러: 팀원의 project-flee가 채택한 방식이나, 본 게임은 그래픽 부하가
  낮아 WebGL 기본이 호환성에서 유리. 필요해지면 별도 ADR로 재검토.

## 영향
정적 호스팅(itch.io, GitHub Pages)으로 배포 가능. 렌더와 시뮬레이션의 분리를
코드 수준에서 강제해야 한다 (architecture.md).
