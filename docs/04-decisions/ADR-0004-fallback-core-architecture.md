# ADR-0004: 폴백 가능한 코어 아키텍처

- 상태: 채택
- 날짜: 2026-08-13

## 맥락
직교 캡처는 이 게임의 독창성이지만 구현·폴리싱 리스크가 가장 큰 부분이다.
기한 내 제출이 최우선이므로 리스크가 실현될 경우의 착지 지점이 필요했다.

## 결정
코어 게임을 "2D 스탬프를 받아 지형으로 배치하는 게임"으로 정의하고,
직교 캡처를 스탬프 생성 소스 모듈로 분리한다 (core는 capture를 모른다).
전체 기간의 1/3 지점을 판정일로 정해 "찰칵 순간이 기분 좋은가"를 평가하고,
미달이면 직교 모듈을 떼고 순수 2D 캡처 + 속성 퍼즐로 착지한다.

## 이유
- 순수 2D 버전도 프레임 제약·속성 규칙만으로 성립하는 완성된 게임이다.
- 모듈 경계가 곧 보험이라 폴백 비용이 모듈 제거 수준으로 낮아진다.
- 팀원의 project-flee가 채택한 "시뮬레이션이 월드를 소유하고 렌더는 스냅샷만
  그린다" 구조와 같은 사상이라 협업 마찰이 없다.

## 고려한 대안
- 직교 캡처에 올인: 실패 시 제출물이 없다. 기각.
- 처음부터 2D만: 독창성 카드를 스스로 버리는 셈. 기각.

## 영향
core/stamp/capture의 import 방향이 강제된다 (완료 조건에 포함).
판정일 이후의 스코프 계획은 판정 결과에 따라 current.md에서 갱신한다.
