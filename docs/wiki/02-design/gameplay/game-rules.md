# Game Rules

## 확정 규칙

- 퍼즐 성격: 혼합형. 클리어는 어떤 해법이든 허용, "최소 캡처 횟수"를 기록해 최적해 유도. 근거는 [[../../04-decisions/ADR-0005-puzzle-rules-hybrid-and-snap|ADR-0005]].
- 위치 규칙: 캡처 프레임 위치는 자유, 붙여넣기 위치는 반 칸(그리드 0.5유닛) 스냅.
- 지형 속성: 돌(기본) / 얼음(미끄러움, 불에 녹음) / 불(접촉 피해, 얼음을 녹임). 같은 스탬프에 불+얼음이 담기면 붙여넣는 순간 얼음 부분이 소멸한다.
- 캡처 금지 구역: 특정 지형은 캡처 불가 태그를 가질 수 있다 (파훼 방지용).
- 레벨 지형은 박스 조합으로만 제작한다 (실루엣 볼록 껍질 방식의 전제).

## 게임 모드와 조작 (v2)
게임은 여러가지 모드를 오간다. 현재는 달리고 뛰는 2D 플랫포머, 그리고 시간을 멈추고 3D 월드를 캡쳐하는 모드, 우클릭 혹은 UI 클릭이 스위치가 된다.

- **Platform**
A/D 이동, Space 점프. 우클릭으로 캡처 조준에 들어간다.

- **CaptureAim**
세계가 멈춘다. 마우스로 프레임을 조준하고, A/D로 카메라를
  돌린다(이 모드에선 이동이 없으니 같은 키를 회전에 재활용한다). 1/2/3으로
  저장할 슬롯을 선택하고 좌클릭이 찰칵.
  우클릭은 마음을 바꾸고 그냥 돌아가기.

- **Paste**
마우스로 자리를 잡고 좌클릭으로 붙인다(반 칸 스냅).
  우클릭은 스탬프를 버리고 Platform으로 복귀.

- **R**
스테이지 리셋. 어떤 모드에서든 통한다.

키를 늘리는 대신 모드가 키의 의미를 바꾼다. 같은 좌클릭이 모드에 따라
캡처가 되고 붙여넣기가 된다. 이 방식이 성립하려면 조건이 하나 있다:
**지금 어느 모드인지 화면만 봐도 알 수 있어야 한다.** 시간 정지 비네트,
프레임 오버레이 같은 시각 신호가 조작 체계의 일부다.

### 모드 규칙

- 캡처 조준 중 세계는 완전히 멈춘다. 움직이는 지형도 그 순간의 모양 그대로
  찍힌다 — 이것 자체가 퍼즐 재료다.
- 스탬프를 든 채로는 Platform으로 돌아갈 수 없다. 붙이거나, 버리거나.
  (들고 다니며 플랫포밍하는 변형은 수직 슬라이스 이후의 확장 후보로 남겨둔다
  — [[../../04-decisions/ADR-0007-game-mode-fsm|ADR-0007]])
- CaptureAim 진입 시 첫 빈 슬롯을 자동 선택한다. 세 슬롯이 모두 차 있으면
  3번 슬롯이 기본 대상이며, 1/2/3으로 대상을 바꿀 수 있다. 캡처하면 선택
  슬롯을 즉시 덮어쓰고 Paste로 전환한다. 덮어쓰기 확인창은 후속 UI 후보다.

## 레벨 커리큘럼 (기술 도입 → 발전 → 반전 → 결합)

- 1~3 캡처-붙여넣기 자체 (정면 고정, 속성 없음, 부분 캡처 학습 포함)
- 4~6 회전 도입 (특정 각도에서만 나오는 모양)
- 7~9 속성 도입 (얼음 → 불, "불을 프레임에서 빼는" 각도 퍼즐)
- 10~12 반전 (불이 도구가 되는 스테이지)
- 13~15 결합 (회전으로 속성을 숨기며 두 깊이를 합치는 하이라이트)
