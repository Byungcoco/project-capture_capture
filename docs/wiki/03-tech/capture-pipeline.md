# Capture Pipeline

입력: 조준 ray(원점, 방향), 시선 basis, 셀 지형 배열, 캡처 스택
출력: CapturedChunk — 셀 격자 오프셋 목록, 각 셀은 원본 재질과 속성 보유

## 절취

1. 조준 ray를 사거리 18m까지 쏘아 첫 collidable 표면을 찾는다
2. 그 표면점을 중심으로 시선 정렬 3m 정육면체 볼륨을 잡는다
3. 볼륨 안에 중심이 들어오는 셀을 선택한다 (최대 216셀)
4. 선택 셀을 지형 배열에서 원자적으로 제거하고, 셀들의 상대 격자 오프셋으로 청크를 만들어 스택에 push한다

캡처 불가 태그를 가진 셀은 선택에서 제외한다. 스택이 5칸을 채우고 있으면 추가 캡처는 상태를 바꾸지 않는다.

## 배치

1. 스택 마지막 청크를 대상으로 삼는다 (LIFO)
2. 조준 ray가 표면에 맞으면 그 면의 바깥쪽 한 셀, 맞지 않으면 정규화한 ray의 20m 끝점을 셀 격자로 내림 양자화해 anchor를 정한다
3. 청크의 격자 오프셋을 회전 없이 anchor에 얹어 최종 셀 목록을 만든다
4. 지형 중복, 플레이어 AABB와의 양의 부피 겹침, 사거리·월드 경계 초과, 중복 target이면 **전체 실패**다
5. 성공하면 셀을 지형에 추가하고 스택에서 pop한다. 둘은 원자적이다

미리보기(홀드)와 확정(릴리스)은 같은 planner와 같은 실패 코드를 쓴다. 배치된 셀은 `owner: player`로 표시되며 collidable·wireable·capturable·destructible이다.

## 결정론

- 셀 선택과 정렬은 격자 인덱스의 안정 순서를 따른다.
- 부동소수 boolean 연산이 없다. 절취 결과는 셀 집합의 차집합, 배치 결과는 합집합이다.
- 같은 틱에 배치된 셀은 그 틱의 충돌·와이어·투사체 차폐에 즉시 참여한다.

확장 여지(현재 범위 아님): 절단면 재질 구분과 면 병합은 표현 계층에서 얹는다. 시뮬레이션 계약은 바뀌지 않는다.

수치와 계약의 코드 원본은 [[../06-code/pivot-runtime|Pivot Runtime]]이다.
